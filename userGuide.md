# QuoteTech - Guia de Usuário

## Bem-vindo ao QuoteTech

**Propósito:** QuoteTech é uma plataforma B2B que fornece cotações de peças de notebook em tempo real, com análise automática de fornecedores e preços atualizados.

**Acesso:** Público (sem necessidade de login para buscar cotações; login opcional para salvar cotações)

---

## Powered by Manus

QuoteTech foi desenvolvido com tecnologia de ponta:

- **Frontend:** React 19 + TypeScript + Tailwind CSS 4 + shadcn/ui
- **Backend:** Express 4 + tRPC 11 (API type-safe)
- **Banco de Dados:** MySQL/TiDB com Drizzle ORM
- **Autenticação:** Manus OAuth integrado
- **Deployment:** Auto-scaling infrastructure com global CDN

---

## Usando o QuoteTech

### 1. Buscar Cotações

Na página inicial, você verá um campo de busca central. Siga estes passos:

1. Clique no campo "Digite o Modelo ou Serial Number"
2. Insira o modelo do seu notebook (exemplo: "Dell G15 5511")
3. Clique no botão verde "Buscar Cotação"
4. Aguarde alguns segundos enquanto a plataforma analisa os fornecedores

### 2. Visualizar Resultados

Após a busca, você será levado para a página de resultados que mostra:

- **Informações da Máquina:** Modelo identificado e imagem do notebook
- **Análise de Mão de Obra:** Nível de dificuldade, tempo estimado e valor sugerido
- **Lista de Peças:** Cada peça mostra preço médio e links para compra em diferentes fornecedores
- **Links de Compra:** Clique em qualquer fornecedor para acessar o produto diretamente

### 3. Exportar ou Salvar Cotação

Na página de resultados, você encontrará dois botões:

- **"Exportar PDF":** Baixa a cotação em formato PDF para compartilhar ou arquivar
- **"Salvar Cotação":** Disponível apenas se você estiver logado; salva a cotação no seu perfil

## Gerenciando Seu Perfil

### Login e Autenticação

Clique no botão "Entrar" no canto superior direito para fazer login com sua conta Manus. Após o login, você poderá:

- Salvar cotações para consultar depois
- Acessar histórico de buscas
- Gerenciar suas preferências

### Sair da Conta

Clique no botão "Sair" para encerrar sua sessão.
